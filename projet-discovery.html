Projet Discovery
Jeu Vidéo Personnel

  • Période : 2022 – 2024
  • Contexte : Projet personnel / BTS SIO
  • Type : Jeu vidéo (solo)
  • Moteur : Unreal Engine
  • Rôle : Game Designer, Développeur, Artiste 3D

Description

Un projet 100% personnel, de bout en bout

Projet de jeu vidéo personnel réalisé en parallèle du BTS SIO, dans le but d'explorer toutes les facettes de la création d'un jeu vidéo : conception, modélisation 3D, développement et son.

J'ai utilisé Unreal Engine pour le moteur, Blender pour la modélisation et le rigging des assets 3D, FL Studio pour la composition musicale et les effets sonores, et Ibis Paint X pour les éléments 2D.

Ce projet m'a permis d'acquérir une vision globale du pipeline de production d'un jeu vidéo indie et de confirmer ma passion pour le Game Design.

Unreal Engine Blender FL Studio Ibis Paint X Game Design 3D Musique

Compétences mobilisées

  • Game Design : conception de mécaniques, niveaux et documents de design
  • Développement avec Unreal Engine (Blueprints)
  • Modélisation et rigging 3D sous Blender
  • Composition musicale et sound design avec FL Studio
  • Création graphique 2D (Ibis Paint X)
  • Gestion complète d'un projet solo (pipeline indie)
  • Autonomie, auto-formation et résolution de problèmes
