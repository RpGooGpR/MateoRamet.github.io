Description

Développement complet : site et application mobile

Projet réalisé dans le cadre du BTS SIO option SLAM. L'objectif était de concevoir et développer une solution numérique complète pour La Gourmetise, une entreprise de restauration fictive.

J'ai développé un site web avec un back-end en PHP / Laravel et une base de données MySQL, ainsi qu'une application mobile Android codée sous Android Studio.

La gestion de projet s'est appuyée sur Trello et le versioning sur GitHub, en respectant un planning ainsi que des spécifications fonctionnelles.
